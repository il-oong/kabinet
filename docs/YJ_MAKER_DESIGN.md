# YJ 가구 메이커 방식 분석 + Kabinet 확장 설계안

> 범위: 설계 제안 문서 (코드 변경 없음). 우선순위 확정 후 단계별로 구현한다.
> 근거: 사용자 제공 스크린샷 3장(YJ 가구 메이커 0.2), 현재 Kabinet 코드(master).
> 인스타그램 원본 영상과 사용자 PC의 저장 프리셋(`Sketchup.read_default('kabinet','presets')`)은
> 이 환경에서 볼 수 없어서, 스크린샷 기준으로 분석했다.

## 1. YJ 가구 메이커 기능 분석 (스크린샷 기준)

### 화면 구성
| 영역 | 내용 | 추정 동작 |
|---|---|---|
| 상단 바 | `선택한 장 불러오기` / `선택한 장 고치기` / `도어 열기/닫기` | 모델의 그룹 속성(JSON)을 폼으로 읽고, 수정하면 같은 그룹을 다시 그림 |
| 좌측 목록 | **상부장**(상부수납장·후드장·상부오픈장·상부코너장), **키큰장**(신발장·키큰수납장·오픈수납장·냉장고장·오븐장·붙박이장), **마무리**(상판·걸레받이·EP/필러·공통 설정) | 카테고리별 템플릿(=프리셋) 선택 |
| 가운데 폼 | 자동 등분, 크기 W/D/H, 도어 개수(자동), 벽에 붙는 쪽, 가운데 지지대(폭 70×18T), 선반 개수 | 장 1개 단위 파라미터 |
| 우측 미리보기 | `앞모습`/`옆 단면` 탭, 도어 열림 방향 점선(삼각형), 하단 요약(도어 2짝·한 짝 398.5×797 등), `마우스로 위치 잡기` | 2D 계산 결과를 즉시 그림 + 배치 도구 |

### 핵심 규칙 (화면 문구에서 읽힌 것)
1. **자동 등분**: "같은 폭으로 나누어 여러 개 만들기" — 총 폭을 N개 장으로 나눔.
2. **도어 개수 자동**: 폭에 따라 1짝/2짝 자동 결정. 한 짝 398.5 = (800 − 3)/2 → **도어 사이 간격 3mm**만 빼고 몸통 전폭을 덮음(풀 오버레이).
3. **벽에 붙는 쪽**: 벽 쪽 도어는 벽에서 3mm 띄움(열림 간섭 방지). 서랍 전판은 서랍 간격만큼, 장과 장 사이는 도어 간격의 절반씩.
4. **가운데 지지대**: 폭이 600을 넘으면 몸통 가운데에 세로 지지대(도어 안쪽)를 넣음. 폭 70, 두께 18, 몸통 앞면에서 뒤로 들임.
5. **공통 설정**: 몸통 두께(15T 선택형), 도어 두께 18, 도어 사이 간격 3, 서랍 사이 간격 4, 몸통–도어 띄움 2,
   상부장·키큰장 도어 윗면 내림 0. **새로 만드는 장부터 적용**되고, 기존 장은 `선택한 장 고치기`로 반영한다.
   입력값은 자동 저장된다(재실행 시 복원).
6. **높이 정의**: "바닥에서 장 윗면까지 (걸레받이 포함, 상판 제외)" — 높이 기준선을 명시해서 혼동을 막음.

### 동작 원리 (추정)
YJ도 **"치수를 늘리는 게 아니라 다시 그리는"** 규칙 기반 생성기로 보인다.
장마다 파라미터 JSON을 그룹 속성에 저장하고, 수정할 때는 그룹 안을 비운 뒤 같은 규칙으로 다시 그린다.
그래서 W를 바꿔도 몸통·도어 두께는 그대로이고, 도어 폭과 지지대 유무만 다시 계산된다.

## 3. 핵심 설계: "두께 유지 + 총치수만 변경" 방법

두 가지 경우를 나눠서 처리한다.

### 3-A. Kabinet으로 만든 장 → **규칙 재생성 (현행 방식 유지·강화)**
```
그룹 속성 spec_json ──▶ Assembly.build_into(그룹) ──▶ 몸통/도어/선반 다시 그림
        ▲                                         │
  폼 수정 · 스케일 도구 · 치수 핸들 ───────────────┘
```
- 사용자가 스케일 도구로 늘리면 → 배율 × 기존 W/D/H → spec만 갱신 → 스케일 없는 상태로 다시 그림.
  두께는 spec에 별도 값이라 변하지 않는다. (생성한 세션에서는 구현됨)
- 추가할 것:
  - **관찰자 재부착**: `Sketchup::AppObserver`(`onOpenModel`·`onNewModel`·`expectsStartupModelNotifications`)와
    플러그인 로드/리로드 시점에 모델 전체(중첩 포함)에서 `spec_json`이 있는 그룹을 찾아 `ScaleAutoRegenObserver`를 다시 붙인다.
    중복 부착 방지를 위해 그룹별 부착 여부를 기억한다. 이게 없으면 다시 연 파일에서 스케일 시 두께가 바뀐다.
  - **도어 개수·지지대 자동 규칙**: 재생성 때 `폭 > 600 → 2짝 + 지지대`처럼 다시 판정 (YJ 동작과 동일).
  - **공통 설정 연동**: spec에 값이 없으면 공통 설정을 쓰고, `고치기`를 누르면 현재 공통 설정을 다시 반영.

### 3-B. 직접 모델링해서 저장해둔 장(규칙이 없는 일반 그룹) → **스트레치 평면 방식**
SketchUp 동적 컴포넌트(DC)는 부재마다 `LenX = Parent!LenX - 2*두께` 같은 수식을 일일이 넣어야 해서
불러온 모델에는 쓰기 어렵다. 대신 **"9분할(9-slice) 스트레치"**를 쓴다.

1. **가져오기 분석**: 모델 안의 판재 그룹마다 외곽 박스를 구하고, 가장 얇은 축을 **두께 축**으로 판정한다
   (예: 18/20/9mm). 이름·재질로 역할(측판/상판/선반/뒷판/도어)을 추정하고 속성에 저장한다.
2. **스트레치 평면**: 축마다 기본 평면 1개(가운데)를 둔다. 필요하면 사용자가 위치를 옮긴다.
3. **치수 변경 규칙** (축마다 Δ = 새 총치수 − 기존 총치수):
   - 평면보다 완전히 **앞/왼쪽/아래**에 있는 부재 → 그대로
   - 완전히 **뒤/오른쪽/위**에 있는 부재 → Δ만큼 **이동**
   - 평면을 **가로지르는** 부재 → 그 축으로만 Δ만큼 **늘림** (두께 축은 평면과 나란하므로 늘어나지 않음)
4. 결과: 측판·상판·도어 두께는 고정, 상판·선반·뒷판 길이만 늘어난다.
5. **도어 재분할**(선택): 도어 역할 부재가 2짝이면 폭을 균등 재계산하고, 600 초과면 경고나 3짝 분할을 제안한다.
6. **원본 보존**: 가져올 때 원본 형상을 **숨긴 원본 컴포넌트 정의**(수정 금지)로 복사해 두고,
   원본 총치수·평면 위치는 속성(`kabinet_stretch`)에 저장한다. 크기를 바꿀 때마다
   원본 정의를 새로 복사 → Δ = 새 치수 − **원본** 치수로 스트레치 → 현재 형상을 교체한다.
   (현재 형상에 원본 기준 Δ를 다시 적용하면 800→900→1000 수정이 1100이 되므로 금지.
   원본을 둘 수 없는 경우에는 Δ를 **현재** 치수 기준으로 계산한다.)

> 3-B는 그룹 안 기하를 편집(`entities.transform_by_vectors` 또는 판재 그룹 재생성)하므로,
> 부재가 **각각 그룹**으로 나뉘어 있을수록 정확하다. 한 그룹에 면이 섞여 있으면 정점 단위 스트레치로 처리한다.

### 그룹 구조 (두 방식 공통)
```
장 그룹 (spec_json 또는 kabinet_stretch)
├── 몸통 그룹: 좌측판 · 우측판 · 상판 · 하판 · 뒷판 · 선반 · 지지대 (각각 그룹)
├── 도어 그룹: 도어1, 도어2 … (각각 그룹, 경첩 축 속성 포함)
└── 마무리 그룹: 걸레받이 · EP/필러 · 상판(마무리)
```

## 4. 도어 열기/닫기

- 생성할 때 도어 그룹마다 속성 저장: `hinge: left|right|top|bottom`, 경첩 축 시작점·방향, `open_angle`(기본 95°),
  서랍은 `slide_mm`(깊이의 70%).
- `도어 열기/닫기` 버튼 → 모든(또는 선택한) 도어 그룹의 transformation을 경첩 축 기준으로 회전하고,
  닫힌 상태 변환을 속성에 보관해서 닫을 때 그대로 복원한다.
- 재생성·도면 출력·재단표는 항상 **닫힌 상태로 되돌린 뒤** 실행한다 (치수 오염 방지).
- 미리보기 앞모습의 **열림 방향 점선 삼각형**(YJ 화면)도 같은 hinge 값으로 그린다.

## 5. 마우스로 위치 잡기
- 생성 대신 배치 도구 실행: 커서에 장 외곽 박스를 미리 보여주고, 클릭한 면에 붙인다.
- 스냅: 바닥(Z=0), 벽면(면 법선 방향으로 뒷면 정렬), 옆 장의 측면(같은 높이·깊이 정렬).
- 벽에 붙은 쪽을 감지하면 `벽에 붙는 쪽` 값을 자동으로 정한다 (도어 3mm 띄움 규칙 연동).

## 6. UI 개편 (YJ 흐름 반영)
- 좌측: 카테고리 트리 (상부장 / 하부장 / 키큰장 / 마무리 / 공통 설정 / 내 프리셋 / **가져온 모델**).
- 가운데: 선택한 템플릿의 필드만 표시. 자주 쓰는 값 위주로 쓰고, 세부 값은 접어둔다.
- 우측: 앞모습/옆 단면 2D 미리보기 + 요약(도어 몇 짝·한 짝 크기·지지대 유무).
- 상단: 선택한 장 불러오기 / 선택한 장 고치기 / 도어 열기·닫기.
- 공통 설정은 `Sketchup.write_default`로 자동 저장한다.

## 7. 단계별 구현 계획 (제안)
| 단계 | 내용 | 규모 |
|---|---|---|
| P1 | 공통 설정 패널 + 자동 저장, 도어 개수 자동·가운데 지지대·벽 쪽 3mm 규칙 (Fitting에 추가) | 중 |
| P2 | 도어 열기/닫기 (경첩 속성 + 회전/복원) | 소~중 |

## 8. 확인이 필요한 사항
1. 저장해둔 모델이 **Kabinet 프리셋**(이 플러그인의 "내 프리셋")인지, **직접 모델링한 .skp/컴포넌트**인지
   → 후자라면 P5(스트레치 방식)가 핵심이다. 샘플 .skp 1~2개를 레포에 올려주면 분석기를 맞춰 만들 수 있다.
2. 몸통 기본 두께: Kabinet은 18T, YJ 화면은 15T. 공통 설정 기본값을 무엇으로 할지.
3. 기존 Kabinet UI를 YJ식으로 **교체**할지, 별도 창(새 메뉴)으로 **병행**할지.
