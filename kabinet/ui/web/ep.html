판재에서 가구까지

EP를 한 장씩 만들고, 직접 조합하세요.

EP 한 장 만들기 단위 mm

가로는 빨강축(X), 두께는 초록축(Y), 높이는 파랑축(Z). 현재 편집 공간의 원점에 한 장을 생성합니다.

내 가구 보관함 이 컴퓨터에 저장

만든 가구의 판재·그룹을 모두 선택한 뒤 저장하세요. 같은 이름도 새 항목으로 보관합니다.

보관함을 불러오고 있습니다…

목록에서 누르고 모델 화면에 클릭하면 배치됩니다. 같은 가구는 컴포넌트로 연결됩니다. 하나만 수정하려면 우클릭 → 고유하게 만들기를 사용하세요.

가구 도면 출력 A3 가로

평면도
컬러 입체도
정면도
측면도
마감재 견본

출력할 판재 또는 조합한 가구 그룹을 선택하세요. 정면은 초록축의 음(-) 방향에서 봅니다. 적용한 재질을 견본으로 넣습니다.

판재를 이동·회전·복사해서 원하는 가구로 조합하세요.
