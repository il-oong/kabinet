판재에서 가구까지

EP를 한 장씩 만들고, 직접 조합하세요.

EP 한 장 만들기 단위 mm

가로는 빨강축(X), 두께는 초록축(Y), 높이는 파랑축(Z). 현재 편집 공간의 원점에 한 장을 생성합니다.

내 가구 보관함 이 컴퓨터에 저장

만든 가구의 판재·그룹을 모두 선택한 뒤 저장하세요. 같은 이름도 새 항목으로 보관합니다.

보관함을 불러오고 있습니다…

목록에서 누르고 모델 화면에 클릭하면 배치됩니다. 같은 가구는 컴포넌트로 연결됩니다. 하나만 수정하려면 우클릭 → 고유하게 만들기를 사용하세요.

가구 도면 출력 A3 가로

바닥 안쪽 경계를 두께 없는 면 한 장으로 만들고 그룹으로 묶어 지정하세요. ㄱ자 바닥도 가능합니다. 문·창문은 개구부 크기의 그룹, 가구는 한 개씩 그룹으로 지정합니다. 지정하지 않은 객체는 출력하지 않습니다.

평면도·입체 배치도·치수표를 출력합니다. 가구는 외곽선만 표시합니다. 벽면도는 가까운 벽 기준이며, 문 열림 방향은 추측하지 않습니다. 치수는 모델 입력값 기준입니다. 공간 전체를 선택한 뒤 아래 출력 버튼을 누르세요.

평면도
컬러 입체도
정면도
측면도
마감재 견본

가구 전체를 선택하고 사용자가 서는 쪽에서 바라본 뒤 정면을 저장하세요. 좌우는 정면에서 가구를 바라보는 기준입니다.

가로 치수는 도어(이웃한 쪽 +1mm · 바깥쪽 +2mm) → EP·몸통장 → 전체 외경의 3단입니다. 앞쪽 얇은 판재는 도어로 추정합니다. 정확히 구분하려면 부품을 선택하고 아래 버튼을 누르세요. 몸통장은 한 통씩 그룹으로 묶어 지정합니다.

측면 기호: 노출면은 삼각형, 벽에 붙는 면은 사선으로 표시합니다. 기호와 범례는 LayOut에서 수정할 수 있습니다.

출력 후 LayOut에서 메모와 정보를 더블클릭해 수정할 수 있습니다. 추가 치수는 도면 끝점에 붙여 찍으세요. 입체 정면도의 사선 깊이는 탑뷰·측면도에서 치수를 추가하세요.

출력할 판재 또는 조합한 가구 그룹을 선택하세요. 정면을 지정하지 않은 가구는 초록축 음(-) 방향으로 출력됩니다. 적용한 재질을 견본으로 넣습니다.

판재를 이동·회전·복사해서 원하는 가구로 조합하세요.
