가구 공통사항 — 이 모델의 모든 Kabinet 가구에 함께 적용

값을 넣은 항목만 모든 가구에 똑같이 적용됩니다. 비워 두면 가구마다 각자 값을 유지합니다. 적용을 누르면 이미 만든 가구도 전부 다시 생성되고, 앞으로 불러오는 프리셋에도 자동으로 들어갑니다. 설정은 이 SketchUp 파일에 저장됩니다.

주방 상판 설치 — 선택한 하부장 위에 한 장으로

① SketchUp에서 상판을 올릴 하부장들을 모두 선택(Ctrl+클릭) → ② 규격 입력 → ③ 설치. 도어 앞면까지 포함한 외곽(손잡이 제외)과 윗면 높이를 자동 인식하고, 일자·ㄱ자·ㄷ자로 꺾인 배치도 하나로 잇습니다.

노출 옆면 = 다른 하부장과 붙어 있지 않은 끝면. 끝이 벽에 닿으면 0으로 두세요. 정면은 Kabinet 가구 정면(또는 도면에서 지정한 정면), 없으면 모델 초록축 −방향입니다.
