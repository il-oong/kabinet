## 0. 원칙 — 원본 가구 치수 불변

1. **원본(B 등 사용자 DWG/DXF)의 가구 치수는 절대 바꾸지 않는다.** 폭·깊이·높이·판 두께·모듈 분할·문 칸수·선반 높이는 원본에서 읽은 값이 정답이다.
2. 최종본(A)에서 가져오는 것은 **양식·표기·구성 규칙뿐**이다: 시트 구성/순서, 도곽·표제란·NOTE 위치, 레이어(색·선굵기), 1:1 실치수와 시트 배율, 블록 구조, DIMENSION 표기(스타일 KAB), 재질 NOTE 문구, 현장 안내 쪽, 힌지 표시 없음, 천판 EP 없음(찬넬 마감), 측판 18T 2장 표기 등.
3. 규칙과 원본 치수가 **충돌**하면 조용히 맞추지 않는다. 확인표(해당 샘플 README)에 `원본값=…, 규칙 적용값=…` 로 병기하고, 사용자가 정하게 한다. 예) 원본 모듈 외곽 1,021 인데 측판 18T×2(36) 규칙을 적용하면 내경이 달라지는 경우.
4. 원본에서 읽기 어려운 값(글자가 폴리선 획으로 변환된 DWG 등)은 `(추정)` 으로 표시해 둔다.

## B. 규칙 해설 (A 에서 확인 + 사용자 지시)

- **시트 순서**: 1 info(현장 안내) · 2 floor(평면) · 3 furniture_B(B면: 평면+도어 정면+몸통 정면) · 4 furniture_A(A면) · 5 side(측면·단면) · 6 detail(상판·EP·찬넬 상세) · 7 table(자재·치수 표). 시트 피치 = 폭 × 1.1 (floor 만 den 20).
- **1:1 실치수**: 모델 공간 좌표 = 실제 mm. 용지 mm = real / den(25, 평면 20). 글자 높이·해치 scale·DIMSTYLE 도 den 배.
- **블록**: 시트 `FRAME_SHEET<n>`, 뷰 `VIEW_*_S<n>`, 노트 `NOTE_S<n>`, 단면 `SECTION_<k>_S<n>`, 상세 `DETAIL_*_S<n>`. 모델 공간에는 INSERT 와 시트 라벨 TEXT(`[n] 제목 (1/den, 1:1 실치수)`, 레이어 SHEET_FRAME_INFO)만 둔다.
- **간격 25**: 도어/서랍 면 사이 틈 25(문 사이·문과 천판·문과 걸레받이). 정면 문 뷰에서 25 DIMENSION 으로 표기.
- **측판 2장**: 모듈(장)마다 18T 측판 2장 → 인접 모듈 사이는 36. 모듈 외곽 폭과 내경(내측 폭) DIMENSION 을 각각 둔다.
- **EP 연속**: 측면 EP 는 바닥까지 내려오며 몸통과 겹치지 않는다(몸통이 EP 안쪽에서 시작). 찬넬(목찬넬 60×40) 마감이면 상부 EP 없음.
- **찬넬 상세**: CH_GAP 25, CH_H 60. 손잡이 = 목찬넬(빨강 NOTE_RED), 힌지 표시 없음.
- **레이어**: OUTLINE(ACI 18, 0.25) 외곽, THIN(8, 0.05) 보조·점선, DIM(252, 0.13) 치수, TEXT(18, 0.13), NOTE_BLUE(5, 0.09), NOTE_RED(242, 0.25), FRAME(18, 1.00), SHEET_FRAME_INFO(8) 라벨.
- **재질 NOTE**: `DOOR : 한솔 엘리 내추럴`, BODY 줄 없음(비어 있으면 줄 생략), `손잡이 : 목찬넬`(빨강).
- **현장 안내(info)**: 주소 `경기도 수원시 영통구 광교호수공원로 80` / `광교아이파크 101동 4601호`, 시공일정(비움) · 특이사항(`한솔 자재 발주, 세라믹 발주 시공일정 체크`), 주의사항(8시50분 차량 입차 불가, 현관번호 7777).
